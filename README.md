# PokéSal 

Repositório para o trabalho da disciplina de Testes e Qualidade de Software. 
Este projeto implementa um sistema de batalha em turnos inspirado (evitando a mafia da nintendo) na franquia Pokémon.

---

##  Como executar usando uma IDE 

Para abrir e rodar o projeto na sua IDE favorita, siga os passos abaixo:

1. Abra a IDE e escolha a opção **"Open"** (ou "Import Project").
2. Selecione a pasta raiz `RepTestesVAFX`.
3. Certifique-se de que a IDE reconheceu a pasta `src/` como a pasta raiz de código (Source Folder) e `pokesal/` como um **Pacote Java** (`package pokesal;`).
4. Navegue até o arquivo `src/pokesal/Main.java`.
5. Clique no botão de **Run** (Geralmente um ícone de "Play" verde) ao lado da declaração `public static void main(String[] args)`.
6. Interaja com o jogo através do console integrado da IDE.

---

##  Como Jogar
* O jogo suporta dois jogadores locais (no mesmo teclado).
* A cada turno, o console exibirá o HP (Vida) e o status do seu pokésal e do adversário.
* Digite `1` para Atacar, `2` para Usar Item ou `3` para Fugir e aperte `ENTER`.
* A batalha encerra quando o HP de algum pokésal chegar a zero, ou se um dos jogadores conseguir fugir com sucesso.
